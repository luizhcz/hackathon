# Usar Codex como única camada de inteligência artificial

Codex será usado tanto para desenvolver a demo quanto para executar toda capacidade de inteligência artificial do produto. O runtime invocará o Codex CLI diretamente por um `CodexRunner` em TypeScript, com três execuções sequenciais, efêmeras e somente leitura para identificar a imagem, pesquisar preço e redigir o Anúncio; OpenAI Agents SDK, `@openai/codex-sdk`, chamadas diretas à Responses API e outros modelos ou serviços de IA ficam fora do projeto. Fallbacks continuam permitidos somente quando forem código determinístico, como tabela de preços, template de texto e fixtures previamente produzidas pelo Codex; aceitamos o acoplamento a processos locais e a possível latência adicional porque a identidade “Codex de ponta a ponta” é parte explícita da demonstração.
